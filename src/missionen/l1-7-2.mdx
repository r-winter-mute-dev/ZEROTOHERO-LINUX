Die Messdaten gehören jetzt einem Team, und Jonas ist nur bis Ende März da. **Deine Mission: Verwalte Gruppen und Mitglieder und lege fest, wie lange Passwörter und Konten gelten.** Lernziel 107.1.

## Gruppen

<Karte nr={1} titel="/etc/group, groupadd, gpasswd">
Jede Gruppe ist eine Zeile in **/etc/group**: Name, Platzhalter `x`, **GID** und die Liste der zusätzlichen Mitglieder:

```
users:x:100:lena,jonas
```

Die **primäre** Gruppe eines Benutzers steht nicht in dieser Liste, sondern als GID in seiner Zeile in `/etc/passwd`. Neue Dateien bekommen die primäre Gruppe (außer in einem Verzeichnis mit SGID, Mission 4.6). Gruppenpasswörter und Gruppenverwalter liegen in **/etc/gshadow**. Gebraucht werden sie heute kaum noch.

| Befehl | Wirkung |
|---|---|
| `groupadd labor` | Gruppe anlegen, `-g 1500` mit fester GID, `-r` als Systemgruppe |
| `groupmod -n team labor` | umbenennen, `-g` ändert die GID |
| `groupdel labor` | löschen, aber nie die primäre Gruppe eines Benutzers |
| `gpasswd -a jonas labor` | jonas aufnehmen, `-d` entfernt ihn |
| `usermod -aG labor jonas` | dasselbe von der Seite des Benutzers |

Neue Gruppen wirken erst nach einer neuen Anmeldung. In der laufenden Sitzung kann jonas mit `newgrp labor` in die Gruppe wechseln.
</Karte>

<Merke>/etc/group: name:x:GID:mitglieder. Die primäre Gruppe steht in /etc/passwd. groupadd, groupmod -n, groupdel, gpasswd -a/-d. Gruppen wirken nach dem nächsten Login.</Merke>

## Wie lange gelten Passwort und Konto?

<Karte nr={2} titel="chage und /etc/login.defs">
Die Felder 3 bis 8 von `/etc/shadow` steuern die **Passwortalterung**. Bequem ändern lassen sie sich mit **chage**:

| Option | Feld | Bedeutung |
|---|---|---|
| `-d` | letzte Änderung | `-d 0` erzwingt eine Änderung bei der nächsten Anmeldung |
| `-m` | Minimum | so viele Tage muss ein Passwort mindestens bleiben |
| `-M` | Maximum | danach muss es geändert werden |
| `-W` | Warnung | so viele Tage vorher wird gewarnt |
| `-I` | inaktiv | so viele Tage nach Ablauf geht noch eine Anmeldung mit Zwang zur Änderung, dann ist das Konto gesperrt |
| `-E` | Ablauf | an diesem Tag (JJJJ-MM-TT) wird das ganze Konto gesperrt, `-E -1` hebt das auf |

`chage -l jonas` zeigt alles lesbar an, und das darf jeder für sein eigenes Konto. `passwd -e jonas` ist die Kurzform von `chage -d 0`, `usermod -e` setzt das Ablaufdatum.

Die Vorgaben für **neue** Konten stehen in `/etc/login.defs`: `PASS_MAX_DAYS 99999` (praktisch nie), `PASS_MIN_DAYS 0`, `PASS_WARN_AGE 7`. Bestehende Konten ändert eine Änderung dort nicht.
</Karte>

<Merke>chage -l zeigt. -M max, -m min, -W Warnung, -I inaktiv, -E Kontoablauf, -d 0 erzwingt Änderung. Vorgaben für neue Konten: PASS_MAX_DAYS, PASS_MIN_DAYS, PASS_WARN_AGE in /etc/login.defs.</Merke>
