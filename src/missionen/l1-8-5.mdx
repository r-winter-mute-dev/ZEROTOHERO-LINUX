## Wer transportiert Mail?

<Karte nr={1} titel="MUA, MTA und die sendmail-Schnittstelle">
Drei Rollen bringen eine Mail ans Ziel:

- Der **MUA** (Mail User Agent) ist das Programm zum Schreiben und Lesen: `mail` in der Shell, Thunderbird, Mutt.
- Der **MTA** (Mail Transfer Agent) nimmt die Mail an und transportiert sie zum Zielserver, über SMTP auf **Port 25**. Unter Linux üblich: **Postfix** (Standard bei vielen Distributionen), **Exim** (lange Debians Vorgabe) und der Urahn **Sendmail**.
- Der **MDA** (Mail Delivery Agent) legt sie ins Postfach, etwa nach `/var/mail/lena`.

Damit Skripte nicht wissen müssen, welcher MTA läuft, bringt jeder MTA dieselben Befehle mit: **/usr/sbin/sendmail** zum Einliefern, **mailq** für die Warteschlange und **newaliases** für die Aliase. Das nennt man die Sendmail-Kompatibilitätsschicht. `echo "Text" | mail -s Betreff root` ruft im Hintergrund genau dieses sendmail auf.

Auf einem einzelnen Server lauscht der MTA oft nur lokal (bei Postfix `inet_interfaces = loopback-only`). Er stellt Mails an lokale Benutzer zu und schickt alles andere an einen Relay-Server weiter (`relayhost`). Mails, die nicht sofort zugestellt werden können, warten in der **Warteschlange**. `mailq` zeigt sie samt Grund.
</Karte>

## Mails umleiten

<Karte nr={2} titel="/etc/aliases, newaliases und ~/.forward">
**/etc/aliases** leitet Adressen auf dem ganzen System um. Jede Zeile hat die Form `name: ziel1, ziel2`:

```
postmaster:  root
webmaster:   root
root:        lena
```

Ziele können lokale Benutzer, andere Aliase, externe Adressen, eine Datei (`/var/log/mails`) oder ein Programm (`|/usr/local/bin/auswerten`) sein. Der MTA liest nicht die Textdatei, sondern eine Datenbank daraus (`/etc/aliases.db`). Nach jeder Änderung baut **newaliases** sie neu, sonst wirkt nichts.

**~/.forward** leitet die Mails eines einzelnen Benutzers um, und das darf jeder selbst. Eine Adresse pro Zeile oder durch Komma getrennt. Ein Backslash vor dem eigenen Namen (`\lena`) behält zusätzlich eine Kopie im eigenen Postfach. Ohne ihn wird nur weitergeleitet.

Häufigster Einsatz: **Mail an root an einen Menschen**. Cron-Ausgaben, Warnungen von smartd und Skripten gehen an root. Mit `root: lena` in /etc/aliases liest sie lena.
</Karte>

<Merke>/etc/aliases: name: ziel, danach newaliases. ~/.forward für einen Benutzer, \name behält eine Kopie. Typisch: root: lena.</Merke>
