## Wiederholen

<Karte nr={1} titel="for, while, until">
**for** geht eine Liste von Wörtern durch:

```
for f in messung/*.csv; do
  echo "$f: $(wc -l < "$f") Zeilen"
done
```

Die Liste kann aus Wildcards kommen, aus festen Wörtern (`for farbe in rot grün blau`) oder aus einer Befehlsersetzung wie `$(seq 1 5)`. **seq** zählt: `seq 5` gibt 1 bis 5 aus, `seq 2 2 10` die geraden Zahlen bis 10. Die Bash kennt außerdem die Zählschleife `for ((i=1; i<=5; i++))`. Ohne `in …` geht for über alle Argumente des Skripts, wie `for a in "$@"`.

**while** wiederholt, **solange** ein Befehl Erfolg meldet, **until**, **bis** er Erfolg meldet:

```
n=0
while [ "$n" -lt 3 ]; do
  n=$((n + 1))
done
until ping -c1 server >/dev/null; do sleep 5; done
```

**Rechnen**: `$(( … ))` rechnet mit ganzen Zahlen: `+ - * / %` und Vergleiche. Variablen brauchen darin kein `$`. `let n++` und `(( n++ ))` gehen auch. Das ältere Programm **expr** braucht Leerzeichen und einen geschützten Stern: `expr 3 \* 4`.

`break` verlässt eine Schleife sofort, `continue` springt zum nächsten Durchlauf.
</Karte>

<Merke>for x in liste; do …; done. while solange Erfolg, until bis Erfolg. seq zählt. $(( n + 1 )) rechnet. break raus, continue weiter.</Merke>

## Eingaben lesen

<Karte nr={2} titel="read und while read">
**read** liest eine Zeile von der Standardeingabe und verteilt sie auf Variablen:

```
read -p "Wie heißt die Messreihe? " reihe
read vorname nachname
```

`-p` zeigt eine Frage an, `-s` verbirgt die Eingabe (für Passwörter), `-r` lässt Backslashes stehen. Bei mehreren Namen bekommt jeder ein Wort, der letzte den ganzen Rest. Ohne Namen landet die Zeile in `REPLY`. Am Ende der Eingabe liefert read den Rückgabewert 1.

Genau das macht read zum Motor für Dateien:

```
while IFS=: read -r user x uid rest; do
  [ "$uid" -ge 1000 ] && echo "$user"
done < /etc/passwd
```

Die Umleitung `< /etc/passwd` steht hinter `done` und gilt für die ganze Schleife. Jeder Durchlauf liest eine Zeile, `IFS=:` trennt am Doppelpunkt statt an Leerzeichen.

Eine Falle: Leitest du die Daten mit einer Pipe hinein (`cut … | while read …`), läuft die Schleife in einer **Subshell**. Variablen, die du darin setzt, sind nach `done` wieder weg. Mit `done < datei` bleiben sie erhalten.
</Karte>

<Merke>read -p "Frage " var, -s still, -r roh. while IFS=: read -r a b rest; do …; done < datei liest Zeile für Zeile. Pipe in die Schleife = Subshell, Variablen gehen verloren.</Merke>
