Niemand im Labor kennt diese Adresse. **Deine Mission: Finde die Verbindung, den Prozess dahinter und den Weg, auf dem er startet. ## Wer redet mit wem?

<Karte nr={1} titel="ss, netstat und lsof">
Jede Netzverbindung ist für den Kernel ein **Socket**. Drei Werkzeuge zeigen sie:

```
ss -tulpn          # t TCP, u UDP, l nur lauschende, p Prozess, n Zahlen statt Namen
ss -tnp            # bestehende TCP-Verbindungen mit Prozess
netstat -tulpn     # dasselbe mit net-tools
lsof -i :4444      # alle Sockets mit Port 4444, lokal oder entfernt
lsof -i TCP -n -P  # alle TCP-Sockets, ohne Namen und Portnamen
```

Den Prozess zum Socket sehen ss und netstat nur als root vollständig. Ohne root bleibt die Spalte bei fremden Prozessen leer.

Lauschende Sockets auf `0.0.0.0` oder `[::]` sind aus allen Netzen erreichbar, solche auf `127.0.0.1` nur vom Rechner selbst. Ob ein Port von außen offen aussieht, prüft man von einem anderen Rechner aus mit `nc -zv werkstatt 22` oder `nmap werkstatt`.
</Karte>

## tcpdump

<Karte nr={2} titel="Pakete ansehen">
**tcpdump** zeigt, was wirklich über eine Schnittstelle geht. Es braucht root (oder die Fähigkeit CAP_NET_RAW) und schaltet die Karte in den Promiscuous Mode.

```
sudo tcpdump -i enp0s31f6 -n -c 10                        # zehn Pakete, ohne Namen
sudo tcpdump -nn port 4444                                 # auch Ports als Zahl
sudo tcpdump -n "host 203.0.113.66 and tcp"
sudo tcpdump -n "udp and (port 53 or port 123)"            # Klammern in Anführungszeichen
sudo tcpdump -n -w beweis.pcap host 203.0.113.66           # in eine Datei schreiben
tcpdump -n -r beweis.pcap                                  # Datei lesen, auch ohne root
```

Ohne `-c` läuft tcpdump, bis man Strg+C drückt, und zählt dann die mitgeschnittenen Pakete. Der Filter (pcap-filter) kennt `host`, `net`, `port`, die Richtungen `src` und `dst`, die Protokolle `tcp`, `udp`, `icmp`, `arp` und die Verknüpfungen `and`, `or`, `not`. Eine Zeile sieht so aus:

```
08:41:12.301000 IP 192.168.1.23.50644 > 203.0.113.66.4444: Flags [P.], seq 88321:88449, ack 1, win 502, length 128
```

Zeit, Absender mit Port, Empfänger mit Port, TCP-Flags (S = SYN, P = PUSH, . = ACK, F = FIN, R = RST) und die Länge der Nutzdaten. Mitschnitte im pcap-Format öffnet auch **Wireshark** grafisch.
</Karte>
