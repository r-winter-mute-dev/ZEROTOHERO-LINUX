Die Firewall des neuen Messnetzes soll nur das durchlassen, was gebraucht wird. Dafür musst du wissen, welcher Dienst welches Protokoll und welchen Port nutzt. **Deine Mission: Unterscheide TCP, UDP und ICMP, lerne die wichtigsten Ports und die Grundzüge von IPv6.** Lernziel 109.1.

## TCP, UDP, ICMP

<Karte nr={1} titel="Drei Protokolle über IP">
- **TCP** baut zuerst eine Verbindung auf (Drei-Wege-Handshake: SYN, SYN/ACK, ACK). Es nummeriert die Daten, bestätigt jedes Stück und schickt Verlorenes neu. Was ankommt, ist vollständig und in der richtigen Reihenfolge. Das kostet Zeit. Typisch: SSH, HTTP, Mail.
- **UDP** schickt einzelne Pakete ohne Verbindung und ohne Bestätigung. Es ist schnell, aber Pakete können fehlen. Typisch: DNS-Anfragen, NTP, Syslog, SNMP, Video.
- **ICMP** trägt Steuer- und Fehlermeldungen von IP selbst, etwa „Ziel nicht erreichbar“ oder „Zeit abgelaufen“. Es hat **keine Ports**. ping schickt ICMP-Echo-Anfragen, traceroute wertet ICMP-Meldungen aus.

TCP und UDP unterscheiden Dienste auf einem Rechner über **Ports** (0 bis 65535). Ports unter 1024 dürfen nur Programme mit Root-Rechten öffnen. Die Zuordnung von Namen zu Nummern steht in **/etc/services**:

| Port | Dienst | | Port | Dienst |
|---|---|---|---|---|
| 20, 21 | FTP (Daten, Steuerung) | | 139 | NetBIOS (Windows-Freigaben) |
| 22 | SSH | | 143 | IMAP |
| 23 | Telnet (unverschlüsselt) | | 161, 162 | SNMP, SNMP-Traps |
| 25 | SMTP | | 389 | LDAP |
| 53 | DNS | | 443 | HTTPS |
| 80 | HTTP | | 465 | SMTP über TLS |
| 110 | POP3 | | 514 | Syslog |
| 123 | NTP | | 636 | LDAP über TLS |
| | | | 993, 995 | IMAP und POP3 über TLS |

## IPv6

<Karte nr={2} titel="Was IPv6 anders macht">
IPv4 hat etwa 4,3 Milliarden Adressen, und die sind vergeben. **IPv6** hat 128 Bit, geschrieben als acht Gruppen hexadezimaler Zahlen: `2001:0db8:0001:0000:0000:0000:0000:0023`. Führende Nullen einer Gruppe dürfen fehlen, und **einmal** pro Adresse ersetzt `::` eine Folge von Nullgruppen: `2001:db8:1::23`.

| IPv4 | IPv6 |
|---|---|
| 32 Bit, dezimal | 128 Bit, hexadezimal |
| Broadcast | kein Broadcast, dafür Multicast (`ff02::1` alle Knoten) |
| NAT gegen Adressmangel | genug Adressen, NAT unnötig |
| ARP | Neighbor Discovery über ICMPv6 |
| DHCP | zusätzlich SLAAC: Der Rechner bildet seine Adresse aus dem Präfix des Routers selbst |
| 127.0.0.1 | `::1` |

Jede IPv6-Schnittstelle hat immer eine **link-lokale** Adresse aus `fe80::/10`, die nur im eigenen Netzabschnitt gilt. Global erreichbare Adressen kommen aus `2000::/3`. Ein Netz ist fast immer ein `/64`. Werkzeuge haben IPv6-Fassungen: `ping6` oder `ping -6`, `traceroute6`, `tracepath6`, `ip -6`.
</Karte>

<Merke>IPv6: 128 Bit, hex, :: einmal pro Adresse. ::1 Loopback, fe80::/10 link-lokal, 2000::/3 global, Netze /64. Kein Broadcast, kein NAT, SLAAC und Neighbor Discovery.</Merke>
