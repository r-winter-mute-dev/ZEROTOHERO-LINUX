## Platten über das Netz

<Karte nr={1} titel="SAN, iSCSI, AoE, FCoE">
Ein **SAN** (Storage Area Network) stellt Blockgeräte über ein Netz bereit. Der Rechner sieht eine ganz normale Platte, partitioniert sie, legt Dateisysteme oder LVM darauf an. Anders als bei NFS oder SMB gibt es kein gemeinsames Dateisystem: Eine iSCSI-Platte gehört in der Regel genau einem Rechner.

- **Fibre Channel (FC):** eigenes Netz mit eigenen Switches und Karten (HBA). Schnell, teuer, im Rechenzentrum verbreitet.
- **FCoE:** Fibre-Channel-Rahmen über Ethernet, spart das zweite Netz, braucht aber verlustfreies Ethernet (DCB).
- **AoE** (ATA over Ethernet): sehr schlicht, direkt auf Ethernet-Ebene ohne IP, also nicht routbar. Treiber aoe, Werkzeuge aoetools, Geräte /dev/etherd/e0.1.
- **iSCSI:** SCSI-Befehle in TCP/IP, Port **3260**. Läuft über jedes normale Netz und ist darum die häufigste Wahl.

Bei iSCSI heißt der Client **Initiator**, der Server **Target**. Beide tragen einen **IQN** (iSCSI Qualified Name) wie `iqn.2026-11.lan.labor:speicher`: Jahr und Monat, in denen die Domain dem Betreiber gehörte, die Domain umgedreht, dann ein frei gewählter Name. Ein Target kann mehrere Platten anbieten, durchnummeriert als **LUN** (Logical Unit Number) 0, 1, 2.

Damit eine Platte über alle Wege und Neustarts hinweg wiedererkannt wird, hat sie eine weltweit eindeutige Kennung, die **WWN** (World Wide Name, bei FC auch für Karten und Ports). Linux nennt die Kennung eines Geräts **WWID** und legt dafür Links unter /dev/disk/by-id/ an. Multipath (mehrere Wege zur selben LUN) erkennt die Wege an derselben WWID.
</Karte>

## open-iscsi

<Karte nr={2} titel="Finden, anmelden, behalten">
Unter Linux ist **open-iscsi** der Initiator: der Dienst **iscsid** und das Werkzeug **iscsiadm**. Der eigene Name steht in /etc/iscsi/initiatorname.iscsi und wird bei der Installation erzeugt. Auf dem Target steht dieser Name in der Zugriffsliste.

```
sudo iscsiadm -m discovery -t sendtargets -p 192.168.50.10    # Welche Targets gibt es?
sudo iscsiadm -m node                                         # gefundene Knoten
sudo iscsiadm -m node -T iqn.2026-11.lan.labor:speicher -p 192.168.50.10 --login
sudo iscsiadm -m session -P 3                                 # Sitzung mit angehängten Platten
sudo iscsiadm -m node -T … --logout
```

Jeder gefundene Knoten bekommt eine Datei unter /etc/iscsi/nodes/. Ihre Werte stammen beim Discovery aus den Vorgaben in **/etc/iscsi/iscsid.conf**. Was danach geändert werden soll, ändert man am Knoten:

```
sudo iscsiadm -m node -o update -n node.session.auth.authmethod -v CHAP
sudo iscsiadm -m node -o update -n node.session.auth.username -v werkstatt
sudo iscsiadm -m node -o update -n node.session.auth.password -v Speicher-2026
sudo iscsiadm -m node -o update -n node.startup -v automatic
```

**CHAP** ist das Anmeldeverfahren von iSCSI. **node.startup = automatic** bewirkt, dass der Dienst open-iscsi beim Start alle solchen Knoten anmeldet. Stehen diese Werte schon vor dem Discovery in iscsid.conf, erben neue Knoten sie gleich.
</Karte>

## Die neue Platte

<Karte nr={3} titel="Welche ist es, und wie bleibt sie es?">
Nach dem Login meldet der Kernel eine neue SCSI-Platte, etwa /dev/sdc. Der Name hängt aber von der Reihenfolge ab, in der Geräte erscheinen. Stabil sind die Links von udev:

```
/dev/disk/by-path/ip-192.168.50.10:3260-iscsi-iqn.2026-11.lan.labor:speicher-lun-0 -> ../../sdc
/dev/disk/by-id/wwn-0x6001405a1b2c3d4e5f60718293a4b5c6                           -> ../../sdc
```

by-path beschreibt den Weg (Portal, Target, LUN), by-id die Platte selbst. Die WWID liefert auch `/lib/udev/scsi_id -g -u -d /dev/sdc`, und `lsscsi` zeigt die Platte mit [Host:Kanal:Ziel:LUN], Hersteller und Modell. Für SCSI-Parameter ist hier **sdparm** zuständig, nicht hdparm.

In der fstab braucht ein Dateisystem auf iSCSI die Option **_netdev**. Daran erkennt systemd, dass es erst nach dem Netz und nach iscsid eingehängt und vor dem Abschalten des Netzes ausgehängt werden muss. Am besten nimmt man dazu die UUID des Dateisystems oder den Namen eines LV.
</Karte>
