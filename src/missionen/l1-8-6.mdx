## Drucken und Warteschlangen

<Karte nr={1} titel="CUPS und die zwei Befehlsfamilien">
Unter Linux druckt **CUPS** (Common UNIX Printing System). Der Dienst **cupsd** nimmt Aufträge an, wandelt sie mit Filtern in die Sprache des Druckers um und schickt sie über ein Backend (ipp, usb, socket, lpd) an das Gerät. Er spricht **IPP** auf **Port 631**. Dort gibt es auch eine Weboberfläche: `http://localhost:631`.

Für das Drucken gibt es zwei Familien von Befehlen. Beide funktionieren unter CUPS:

| Aufgabe | System V | BSD (lpd) |
|---|---|---|
| drucken | `lp -d laser datei` | `lpr -P laser datei` |
| Kopien | `lp -n 2` | `lpr -#2` |
| Warteschlange | `lpstat -o` | `lpq -P laser` |
| Auftrag löschen | `cancel laser-12` | `lprm 12` |
| alle eigenen löschen | `cancel -a` | `lprm -` |

Ohne Druckername geht der Auftrag an den Standarddrucker. `lpstat -t` zeigt alles auf einmal: läuft der Dienst, welcher Drucker ist Standard, welche Geräte, nimmt er an, druckt er, welche Aufträge warten.

Ein Drucker hat zwei Schalter. **cupsdisable** hält ihn an: Er nimmt weiter Aufträge an, druckt aber nicht. **cupsenable** lässt ihn weiterdrucken. **cupsreject** lehnt neue Aufträge ab, **cupsaccept** nimmt wieder an. So kannst du einen Drucker für eine Reparatur anhalten, ohne dass Aufträge verloren gehen.
</Karte>

## Drucker einrichten

<Karte nr={2} titel="lpadmin, lpoptions und die Dateien">
Moderne Netzwerkdrucker verstehen **IPP Everywhere**: CUPS fragt sie selbst nach ihren Fähigkeiten und braucht keinen Treiber. Einrichten geht in der Weboberfläche oder mit **lpadmin**:

```
lpadmin -p labor -E -v ipp://192.168.1.41/ipp/print -m everywhere
```

`-p` gibt den Namen, `-E` aktiviert den Drucker und lässt ihn Aufträge annehmen, `-v` ist das Gerät (Device URI), `-m` das Modell. `lpinfo -v` zeigt die gefundenen Geräte, `lpinfo -m` die verfügbaren Modelle. `lpadmin -d labor` macht labor zum Standard des Systems, `lpadmin -x labor` löscht ihn. Jeder Benutzer kann mit `lpoptions -d labor` einen eigenen Standard wählen. Der steht dann in `~/.cups/lpoptions`.

Die Dateien liegen unter **/etc/cups/**: `cupsd.conf` steuert den Dienst (`Listen`, Zugriffsrechte in `<Location>`-Abschnitten, `WebInterface`), `printers.conf` schreibt cupsd selbst, solange er läuft. Fehler stehen in `/var/log/cups/error_log`, Aufträge warten in `/var/spool/cups/`. Wer Drucker verwalten darf, regelt auf Debian die Gruppe **lpadmin**.
</Karte>

<Merke>lpadmin -p NAME -E -v URI -m everywhere, -d Standard, -x löschen. lpoptions -d für den eigenen Standard. /etc/cups/cupsd.conf, printers.conf (nicht von Hand), /var/log/cups/error_log, Gruppe lpadmin.</Merke>
