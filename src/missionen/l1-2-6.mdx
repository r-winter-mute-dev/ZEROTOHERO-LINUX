Jetzt wechselst du zur zweiten Familie: Red Hat, AlmaLinux, Rocky, Fedora und SUSE nutzen **RPM-Pakete**. Das Werkzeug **rpm** entspricht dpkg: Es arbeitet mit einzelnen Dateien und mit der Datenbank der installierten Pakete. **Deine Mission: Frag die RPM-Datenbank ab und untersuche eine Paketdatei, bevor du sie installierst.** Lernziel 102.5.

## Pakete abfragen

<Karte nr={1} titel="Der Dateiname verrät viel">
```
messsoft-1.2-1.el9.x86_64.rpm
```

Das ist **Name** (messsoft), **Version** (1.2), **Release** (1.el9, also erste Paketierung für Enterprise Linux 9) und **Architektur** (x86_64). `noarch` hieße: läuft überall, zum Beispiel ein Skript.

Abfragen beginnen alle mit `-q` (query):

| Befehl | Zeigt |
| --- | --- |
| `rpm -q bash` | ob bash installiert ist und in welcher Version |
| `rpm -qa` | alle installierten Pakete |
| `rpm -qi bash` | Informationen: Version, Größe, Signatur, Beschreibung |
| `rpm -ql bash` | alle Dateien des Pakets |
| `rpm -qc httpd` | nur die Konfigurationsdateien |
| `rpm -qR bash` | Abhängigkeiten (requires) |
| `rpm -qf /usr/bin/rpm` | zu welchem Paket die Datei gehört |
</Karte>

<Merke>rpm -q + Buchstabe: a alle, i Infos, l Dateien, c Konfiguration, R Abhängigkeiten, f welches Paket.</Merke>

<Hinweis titel="Die Buchstaben von rpm -V">
rpm -V zeigt nur, was abweicht. Jede Stelle steht für eine Eigenschaft, ein Punkt heißt „unverändert“: S Größe, M Rechte, 5 Prüfsumme, D Gerätenummer, L Link, U Besitzer, G Gruppe, T Änderungszeit. Das c markiert eine Konfigurationsdatei. Mit rpm -Va prüfst du alle Pakete auf einmal.
</Hinweis>

## Eine Paketdatei

<Karte nr={2} titel="Installieren, aktualisieren, entfernen">
| Befehl | Tut |
| --- | --- |
| `rpm -ivh datei.rpm` | **i**nstalliert, **v**erbose, mit **h**ash-Fortschrittsbalken |
| `rpm -Uvh datei.rpm` | **U**pgrade: aktualisiert, oder installiert, wenn es noch nicht da ist |
| `rpm -Fvh datei.rpm` | **F**reshen: aktualisiert nur, wenn eine ältere Version installiert ist |
| `rpm -e name` | **e**rase: entfernt das Paket (hier der Name, nicht die Datei) |
| `rpm --reinstall datei.rpm` | installiert dieselbe Version noch einmal |

Eine Datei, die noch **nicht** installiert ist, fragst du mit zusätzlichem **-p** ab: `rpm -qpi datei.rpm`, `rpm -qpl datei.rpm`, `rpm -qpR datei.rpm`.

Wie dpkg löst rpm **keine** Abhängigkeiten aus dem Netz auf. Fehlt etwas, bricht es mit „Failed dependencies“ ab. Das erledigt dnf (nächste Mission).
</Karte>

<Karte nr={3} titel="Signatur und Auspacken">
Pakete aus den offiziellen Quellen sind mit einem GPG-Schlüssel **signiert**. `rpm -K datei.rpm` (gleichbedeutend `rpmkeys --checksig`) prüft Prüfsummen und Signatur. Schlüssel importiert man mit `rpm --import schluesseldatei`, sie liegen meist unter `/etc/pki/rpm-gpg/`.

Willst du nur eine einzelne Datei aus einem Paket, ohne es zu installieren: `rpm2cpio datei.rpm | cpio -idmv`. rpm2cpio wandelt das Paket in ein cpio-Archiv, cpio packt es ins aktuelle Verzeichnis aus (i auspacken, d Verzeichnisse anlegen, m Zeitstempel behalten, v ausführlich).
</Karte>

<Merke>-U installiert oder aktualisiert, -F nur aktualisieren. -p fragt Dateien ab. rpm2cpio | cpio -idmv packt aus.</Merke>
