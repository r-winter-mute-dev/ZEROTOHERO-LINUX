Die Firma hat für die Werkstatt ein Messprogramm gekauft. Es liegt unter `/opt/messsoft`. Wer es startet, bekommt nur eine Fehlermeldung. **Deine Mission: Finde heraus, welche Bibliothek fehlt, und bring das Programm zum Laufen.** Lernziel 102.3.

## Gemeinsame Bibliotheken

<Karte nr={1} titel="Code, den sich alle teilen">
Viele Programme brauchen dieselben Funktionen: Text ausgeben, Dateien öffnen, Netzwerk. Statt dass jedes Programm diesen Code selbst mitbringt, liegt er einmal in einer **gemeinsamen Bibliothek** (shared library, „shared object“). Du erkennst sie an der Endung **.so**, oft mit einer Versionsnummer: `libc.so.6`.

Startet ein Programm, sucht der **dynamische Linker** (`ld-linux.so`) die nötigen Bibliotheken und lädt sie dazu. Typische Orte sind `/lib` und `/usr/lib`, auf 64-Bit-Systemen von Red Hat `/lib64` und `/usr/lib64`, auf Debian `/lib/x86_64-linux-gnu`. Selbst installierte Bibliotheken liegen meist in `/usr/local/lib`.

`ldd /usr/bin/ls` zeigt, welche Bibliotheken ein Programm braucht und wo der Linker sie findet. Steht dort **not found**, fehlt eine.
</Karte>

<Merke>.so = gemeinsame Bibliothek. ldd zeigt, was ein Programm braucht. „not found“ heißt: fehlt.</Merke>

## Den Linker informieren

<Karte nr={2} titel="ldconfig und /etc/ld.so.conf">
Der Linker durchsucht nicht bei jedem Start die ganze Platte, sondern liest einen **Cache**: **/etc/ld.so.cache**. Den baut **ldconfig** auf. Es durchsucht die Standardverzeichnisse und alle Verzeichnisse, die in **/etc/ld.so.conf** stehen. Diese Datei bindet meist nur **/etc/ld.so.conf.d/*.conf** ein, so dass jedes Programm seine eigene kleine Datei mitbringen kann.

Eine neue Bibliothek dauerhaft bekannt machen, in zwei Schritten:

```
echo /opt/messsoft/lib | sudo tee /etc/ld.so.conf.d/messsoft.conf
sudo ldconfig
```

`ldconfig -p` zeigt danach, was im Cache steht.
</Karte>

<Merke>Verzeichnis in /etc/ld.so.conf.d/*.conf eintragen, dann sudo ldconfig.</Merke>

<Karte nr={3} titel="LD_LIBRARY_PATH: nur für diesen Aufruf">
Willst du nur kurz etwas ausprobieren, sagst du dem Linker das Verzeichnis über die Umgebungsvariable **LD_LIBRARY_PATH**:

```
LD_LIBRARY_PATH=/opt/messsoft/lib /opt/messsoft/bin/messprog
```

So gilt sie nur für diesen einen Aufruf. Mit `export LD_LIBRARY_PATH=/opt/messsoft/lib` gilt sie für alle weiteren Befehle in dieser Shell, bis du sie schließt. Für den Dauerbetrieb ist der Weg über ldconfig besser: Er gilt für alle Benutzer und übersteht einen Neustart.
</Karte>

<Merke>LD_LIBRARY_PATH zum Ausprobieren, ld.so.conf.d plus ldconfig für immer.</Merke>
