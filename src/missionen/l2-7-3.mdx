Bisher hat sich niemand um die Sicherung von werkstatt gekümmert. Auf dem Rechner liegen inzwischen der Lagerbestand unter /srv/lager, Konfigurationen und die Home-Verzeichnisse. Unter /mnt/backup hängt seit gestern eine USB-Platte. **Deine Mission: Leg ein Sicherungskonzept fest, mach eine Vollsicherung und eine inkrementelle Sicherung mit tar, prüf beide und hol eine gelöschte Datei zurück.** Lernziel 206.2.

## Was, wie oft, wohin

<Karte nr={1} titel="Welche Verzeichnisse in die Sicherung gehören">
Eine Sicherung soll den Rechner nach einem Ausfall wiederherstellen. Das System selbst lässt sich neu installieren, die eigenen Daten und Einstellungen nicht.

- **Immer sichern:** `/etc` (Konfiguration), `/home` und `/root`, `/srv` (Daten der Dienste), `/usr/local` und `/opt` (selbst Installiertes), aus `/var` vor allem `/var/lib` (Daten von Diensten), `/var/spool` (cron-Tabellen, Mail-Warteschlangen) und `/var/mail`. Dazu eine Liste der Pakete: `dpkg --get-selections` oder `rpm -qa`.
- **Nie sichern:** `/proc` und `/sys` (erzeugt der Kernel zur Laufzeit), `/dev` und `/run`, `/tmp`, Einhängepunkte wie `/mnt` und `/media` (sonst sichert man die Sicherungsplatte mit), Swap.
- **Mit Vorsicht:** Laufende Datenbanken. Eine Kopie der Dateien mitten im Schreiben ist oft unbrauchbar. Besser ein Dump (`pg_dump`, `mysqldump`) oder ein LVM-Snapshot wie in Akt 5.
</Karte>

<Karte nr={2} titel="Sicherungsarten und Medien">
Eine **Vollsicherung** enthält alles. Eine **inkrementelle** Sicherung enthält nur, was sich seit der **letzten Sicherung** (gleich welcher Art) geändert hat. Eine **differenzielle** enthält alles seit der **letzten Vollsicherung**. Zum Wiederherstellen braucht man bei inkrementell die Vollsicherung und **alle** Stufen danach, bei differenziell nur die Vollsicherung und die **letzte** Differenz. Bewährt hat sich die Faustregel 3-2-1: drei Kopien, zwei verschiedene Medien, eine davon außer Haus.

| Medium | Vorteile | Nachteile |
|---|---|---|
| Band (LTO) | billig pro TB, lange haltbar, lagert offline | langsam beim Suchen, teures Laufwerk |
| CD-R, DVD, Blu-ray | billig, einmal beschreibbar | wenig Platz, langsam, altert |
| Festplatte, USB | schnell, wahlfreier Zugriff | eingehängt angreifbar (Ransomware), mechanisch empfindlich |
| Netz, Cloud | automatisch außer Haus | hängt an Bandbreite, Vertrauen, Kosten |

Für viele Rechner gibt es Lösungen über das Netz: **Amanda** steuert tar und dump zentral und schreibt gern auf Band. **Bacula** trennt Director, Storage Daemon, File Daemon und einen Katalog in einer Datenbank. **Bareos** ist eine Abspaltung von Bacula. **BackupPC** sichert auf Platte, legt gleiche Dateien nur einmal ab und braucht auf den Clients keine eigene Software.
</Karte>

## Sichern mit tar

<Karte nr={3} titel="Voll, inkrementell, vergleichen, zurückholen">
GNU tar führt mit `-g DATEI` (`--listed-incremental`) eine **Snapshot-Datei**. Gibt es sie noch nicht, wird eine Vollsicherung (Stufe 0) daraus. Jeder weitere Lauf mit derselben Datei sichert nur Geändertes und schreibt den neuen Stand hinein.

```
sudo tar czf /mnt/backup/voll.tar.gz -g /mnt/backup/stand.snar /etc /home /srv
sudo tar czf /mnt/backup/inkr1.tar.gz -g /mnt/backup/stand.snar /etc /home /srv
```

Für **differenzielle** Sicherungen kopiert man vor jedem Lauf die Snapshot-Datei der Vollsicherung und gibt tar die Kopie.

Sicherungen sind erst etwas wert, wenn sie lesbar sind:

```
sha256sum voll.tar.gz | sudo tee SHA256SUMS; sha256sum -c SHA256SUMS
tar tzf voll.tar.gz > /dev/null        # lässt sich alles lesen?
sudo tar dzf voll.tar.gz -C /          # was hat sich seitdem geändert?
```

`tar d` (`--diff`, `--compare`) meldet Dateien, deren Inhalt, Größe, Rechte oder Zeit abweicht. Neue Dateien erwähnt es nicht. Zum **teilweisen** Zurückholen nennt man die Namen wie im Archiv, ohne führendes `/`: `tar xzf voll.tar.gz -C / srv/lager/preise.csv`. Wer unsicher ist, packt erst nach `/tmp` aus und kopiert dann. Eine Kette inkrementeller Archive spielt man der Reihe nach mit `-g /dev/null` ein, dann löscht tar auch, was zwischendurch entfernt wurde.
</Karte>
