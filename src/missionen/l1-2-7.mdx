Was apt für Debian ist, ist **dnf** für Red Hat und seine Verwandten und **zypper** für SUSE: Sie holen Pakete aus Repositories und lösen Abhängigkeiten auf. Das Lernziel heißt noch „RPM und YUM“, weil yum der Vorgänger von dnf ist. **Deine Mission: Installiere Software auf AlmaLinux und auf openSUSE.** Lernziel 102.5.

## yum und dnf

<Karte nr={1} titel="Zwei Namen, eine Bedienung">
**yum** war jahrelang das Werkzeug auf Red Hat Enterprise Linux und CentOS. Seit RHEL 8 ist **dnf** sein Nachfolger. Der Befehl `yum` ist dort nur noch ein anderer Name für dnf. Die Befehle sind fast gleich:

| Befehl | Tut |
| --- | --- |
| `dnf install tree` | installiert samt Abhängigkeiten |
| `dnf install ./datei.rpm` | installiert eine lokale Datei und holt fehlende Abhängigkeiten |
| `dnf remove tree` | entfernt |
| `dnf upgrade` (alt: `yum update`) | aktualisiert alles |
| `dnf search begriff` | sucht in Namen und Beschreibungen |
| `dnf info tree` | zeigt Infos |
| `dnf provides /usr/bin/tree` | welches Paket liefert diese Datei, auch wenn es nicht installiert ist |
| `dnf list installed` | installierte Pakete |
| `dnf repolist` | aktive Repositories |

Vorsicht bei der Rückfrage: dnf fragt „Is this ok [y/N]“. Der Großbuchstabe ist die Vorgabe, Enter heißt hier **Nein**. Mit `-y` fällt die Frage weg.
</Karte>

<Karte nr={2} titel="Wo die Quellen stehen">
Jedes Repository steht in einer eigenen Datei unter **/etc/yum.repos.d/** mit der Endung .repo:

```
[baseos]
name=AlmaLinux $releasever - BaseOS
mirrorlist=https://mirrors.almalinux.org/mirrorlist/$releasever/baseos
enabled=1
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-AlmaLinux-9
```

Allgemeine Einstellungen stehen in **/etc/yum.conf**, bei dnf in **/etc/dnf/dnf.conf**. Auf AlmaLinux 9 ist yum.conf nur ein Link auf dnf.conf. Viele beliebte Pakete fehlen in den offiziellen Quellen. Sie liegen in **EPEL** (Extra Packages for Enterprise Linux), das man mit `dnf install epel-release` einschaltet.
</Karte>

<Merke>dnf = Nachfolger von yum. Quellen in /etc/yum.repos.d/*.repo. Vorgabe bei [y/N] ist Nein.</Merke>

<Hinweis titel="Enter ist hier Nein">
Wer von Debian kommt, drückt bei der Rückfrage gewohnheitsmäßig Enter und wundert sich über „Operation aborted“. Bei apt ist Y die Vorgabe, bei dnf N.
</Hinweis>

## zypper

<Karte nr={3} titel="SUSE hat sein eigenes Werkzeug">
openSUSE und SUSE Linux Enterprise nutzen ebenfalls RPM-Pakete, aber **zypper** statt dnf. Jeder Befehl hat eine Kurzform:

| Befehl | Kurz | Tut |
| --- | --- | --- |
| `zypper refresh` | `ref` | Repository-Daten neu laden |
| `zypper install` | `in` | installieren |
| `zypper remove` | `rm` | entfernen |
| `zypper update` | `up` | aktualisieren |
| `zypper search` | `se` | suchen |
| `zypper info` | `if` | Infos |
| `zypper what-provides` | `wp` | welches Paket liefert eine Datei |
| `zypper repos` | `lr` | Repositories anzeigen |
| `zypper addrepo` | `ar` | Repository hinzufügen |

Die Repositories stehen unter **/etc/zypp/repos.d/**.
</Karte>

<Merke>zypper: in, rm, up, se, if, wp, ref, lr, ar. Quellen in /etc/zypp/repos.d.</Merke>
