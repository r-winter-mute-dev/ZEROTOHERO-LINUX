## Der Prompt

<Karte nr={1} titel="Was links vom Cursor steht">
Wenn ein Terminal auf deine Eingabe wartet, zeigt es den **Prompt**, zum Beispiel:

```
lena@werkstatt:~$
```

Das heißt: Benutzer **lena** auf dem Rechner **werkstatt**, im Verzeichnis **~** (das ist dein persönliches Verzeichnis, hier `/home/lena`). Das **$** am Ende zeigt einen normalen Benutzer. Arbeitest du als Administrator **root**, steht dort ein **#**. Dann besonders aufpassen: root darf alles, auch das System zerstören.
</Karte>

<Merke>$ heißt normaler Benutzer, # heißt root. Die Tilde ~ ist dein persönliches Verzeichnis.</Merke>

## Befehle, Optionen, Argumente

<Karte nr={2} titel="Ein Befehl in drei Teilen">
```
ls -l /etc
```

- **ls** ist der **Befehl**: Er listet Dateien auf.
- **-l** ist eine **Option**: Sie verändert, wie der Befehl arbeitet, hier als ausführliche Liste.
- **/etc** ist ein **Argument**: Es sagt, *womit* der Befehl arbeitet.

Kurze Optionen haben einen Strich und einen Buchstaben und lassen sich zusammenfassen: `ls -l -a` ist dasselbe wie `ls -la`. Lange Optionen haben zwei Striche und ein Wort, etwa `ls --all`. Linux unterscheidet Groß- und Kleinschreibung: `-r` und `-R` sind zwei verschiedene Optionen.
</Karte>

<Merke>befehl -optionen argumente. Groß und klein ist nicht egal.</Merke>

<Karte nr={3} titel="Hilfe ist immer eingebaut">
Fast jeder Befehl hat eine Handbuchseite: `man ls`. Darin blätterst du mit den Pfeiltasten, suchst mit `/` und einem Suchwort und beendest mit **q**. Kürzer geht es oft mit `ls --help`. In der Prüfung hast du keine Handbuchseiten. Beim Üben sind sie aber der schnellste Weg, eine Option nachzuschlagen.
</Karte>

## Die wichtigsten Griffe

<Karte nr={4} titel="Bewegen und anschauen">
| Befehl | Was er tut |
| --- | --- |
| `pwd` | zeigt, wo du bist (print working directory) |
| `ls` | listet den Inhalt eines Verzeichnisses |
| `cd /etc` | wechselt nach /etc, `cd ..` eine Ebene hoch, `cd` allein nach Hause |
| `cat datei` | gibt eine Datei aus |
| `less datei` | zeigt eine lange Datei seitenweise, **q** beendet |
| `uname -r` | zeigt die Version des laufenden Kernels |

Pfade, die mit `/` beginnen, sind **absolut** und gelten von überall. Alle anderen sind **relativ** zum aktuellen Verzeichnis.
</Karte>

<Karte nr={5} titel="Drei Tasten, die dir Zeit sparen">
- **Tab** ergänzt Befehle und Pfade. Zweimal Tab zeigt alle Möglichkeiten.
- **Pfeil nach oben** holt den letzten Befehl zurück. So musst du nach einem Tippfehler nicht alles neu schreiben.
- **Strg+C** bricht einen laufenden Befehl ab.
</Karte>

<Karte nr={6} titel="sudo: kurz mal Administrator">
Viele Befehle in diesem Kurs ändern das System und brauchen deshalb Administratorrechte. Statt dich als root anzumelden, setzt du `sudo` davor: `sudo modprobe -r pcspkr`. Beim ersten Mal fragt sudo nach *deinem* Passwort. Ohne sudo bekommst du Meldungen wie „Operation not permitted“ oder „Access denied“. Das ist kein Fehler des Befehls, sondern der Hinweis: Hier fehlen Rechte.
</Karte>

<Merke>Fehlt das Recht, kommt „Operation not permitted“ oder „Access denied“. Dann sudo davor.</Merke>
