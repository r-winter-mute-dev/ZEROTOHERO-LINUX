## Aliase

<Karte nr={1} titel="Abkürzungen mit alias">
Ein **Alias** ersetzt das erste Wort einer Befehlszeile durch einen Text:

```
alias ll='ls -l'
alias rm='rm -i'
```

Die Anführungszeichen sind nötig, weil der Text Leerzeichen enthält. `alias` ohne Argument zeigt alle Aliase, `alias ll` nur eines, `unalias ll` löscht es, `unalias -a` alle.

Ein Alias kann einen Befehl gleichen Namens verdecken, wie oben `rm`. Willst du einmal das Original, schreibst du einen Backslash davor (`\rm`), nimmst `command rm` oder den vollen Pfad `/usr/bin/rm`.

Aliase haben Grenzen: Sie wirken nur am Anfang einer Zeile, sie kennen keine Argumente in der Mitte, und in Skripten sind sie normalerweise aus. Für alles, was mehr als eine feste Abkürzung ist, nimmst du eine Funktion.

`type ll` zeigt, was hinter einem Namen steckt. Die Bash sucht in dieser Reihenfolge: **Alias, Schlüsselwort, Funktion, eingebauter Befehl, Programm im PATH.**
</Karte>

<Merke>alias ll='ls -l', unalias ll. \ls oder command ls umgeht das Alias. Reihenfolge: Alias, Schlüsselwort, Funktion, eingebaut, PATH. type zeigt, was gewinnt.</Merke>

## Funktionen

<Karte nr={2} titel="Eigene Befehle mit Funktionen">
Eine **Funktion** ist ein kleines Programm in der Shell selbst. Zwei Schreibweisen sind erlaubt:

```
mkcd() {
  mkdir -p "$1" && cd "$1"
}

function mkcd { mkdir -p "$1" && cd "$1"; }
```

In einer Zeile braucht die Bash ein Semikolon vor der schließenden Klammer und Leerzeichen hinter `{`. Im Rumpf sind `$1`, `$2` … die Argumente des Aufrufs, `$#` ihre Anzahl und `"$@"` alle zusammen. `local name=wert` legt eine Variable an, die nur in der Funktion gilt. `return 3` beendet die Funktion mit einem Rückgabewert.

Eine Funktion läuft **in der laufenden Shell**, nicht in einem Kindprozess. Darum wirkt ihr `cd` hinterher, und sie sieht auch Variablen, die nicht exportiert sind. Ein Skript kann das nicht.

`type mkcd` und `declare -f mkcd` zeigen den Quelltext, `declare -f` alle Funktionen, `set` ebenfalls. `unset -f mkcd` löscht eine Funktion.

Wie Aliase leben Funktionen nur bis zum Ende der Shell. Damit sie in jedem neuen Terminal da sind, gehören beide in `~/.bashrc`. Auf Debian liest die `~/.bashrc` außerdem `~/.bash_aliases`, wenn die Datei existiert. Nach einer Änderung liest du sie mit `source ~/.bashrc` neu ein.
</Karte>

<Merke>`name() { befehle; }` mit $1, $2, $#, "$@", local, return. Läuft in der laufenden Shell, darum wirkt cd. Dauerhaft in ~/.bashrc. unset -f löscht.</Merke>

</Hinweis>
