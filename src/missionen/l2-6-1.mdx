Das Labor zieht um. Im neuen Raum hängt werkstatt an einem Switch, der mehrere Netze über ein Kabel führt: das normale Büronetz und, als VLAN 20, das Netz der Messgeräte. Außerdem soll werkstatt für eine Übergangszeit unter einer zweiten Adresse erreichbar sein, weil alte Skripte noch 192.168.1.50 ansprechen. **Deine Mission: Gib der Netzwerkkarte eine zweite Adresse, richte die VLAN-Schnittstelle ein und sorg mit einer Route dafür, dass werkstatt das Netz hinter den Messgeräten findet.** Lernziel 205.1.

## Werkzeuge alt und neu

<Karte nr={1} titel="iproute2 und net-tools">
Unter Linux gibt es zwei Werkzeugfamilien für das Netz:

- **net-tools** mit `ifconfig`, `route`, `arp` und `netstat`. Sie stammen aus den 1990ern, werden nicht mehr weiterentwickelt und sind auf vielen Systemen gar nicht mehr installiert. Für die Prüfung musst du sie trotzdem lesen und bedienen können.
- **iproute2** mit `ip` und `ss`. Ein Programm für alles, mit Objekten wie `link`, `address`, `route`, `neigh` und Abkürzungen wie `ip a`, `ip r`, `ip l`, `ip n`.

```
ip -br addr                     # kurz: Schnittstelle, Zustand, Adressen
ip addr show dev enp0s31f6       # ausführlich
ip -d link show                  # mit Details wie VLAN-ID oder Typ
ip -4 route                      # nur IPv4
ifconfig -a                      # auch ausgeschaltete Schnittstellen
route -n                         # Routentabelle ohne Namensauflösung
```

Ein wichtiger Unterschied: `ifconfig` zeigt pro Schnittstelle nur **eine** IPv4-Adresse. Weitere Adressen sieht es nur, wenn sie ein **Label** wie `enp0s31f6:web` tragen. Dann erscheinen sie als eigene „Alias-Schnittstelle“.

**Alles, was du mit `ip` oder `ifconfig` einstellst, gilt nur bis zum nächsten Neustart.** Wie man es dauerhaft macht, kommt in Mission 6.6.
</Karte>

## Adressen, MTU, VLAN

<Karte nr={2} titel="Eine Karte, mehrere Gesichter">
**Zusätzliche Adressen** hängst du einfach an:

```
sudo ip addr add 192.168.1.50/24 dev enp0s31f6 label enp0s31f6:web
sudo ifconfig enp0s31f6:1 192.168.1.51 netmask 255.255.255.0       # dasselbe mit net-tools
sudo ip -6 addr add 2001:db8:1::50/64 dev enp0s31f6
```

Eine zweite Adresse aus demselben Netz markiert `ip addr` als **secondary**. Löscht man die primäre, entfernt der Kernel standardmäßig auch die secondary-Adressen dieses Netzes. Erst mit `net.ipv4.conf.all.promote_secondaries=1`, das systemd auf vielen Systemen setzt, rückt stattdessen eine secondary-Adresse nach.

Die **MTU** (Maximum Transmission Unit) ist das größte Paket, das eine Schnittstelle am Stück verschickt, im Ethernet normal 1500 Byte. In Speichernetzen nutzt man **Jumbo Frames** mit 9000 Byte, dann aber auf allen Geräten im Netz:

```
sudo ip link set dev enp0s31f6 mtu 9000
```

Ein **VLAN** (802.1Q) trennt mehrere logische Netze auf einem Kabel. Der Switch kennzeichnet jedes Paket mit einer VLAN-ID (1 bis 4094). Linux legt dafür eine eigene Schnittstelle an, das Kernelmodul heißt `8021q`:

```
sudo ip link add link enp0s31f6 name enp0s31f6.20 type vlan id 20
sudo ip addr add 10.20.20.23/24 dev enp0s31f6.20
sudo ip link set enp0s31f6.20 up
```

Weitere virtuelle Typen: `dummy` (eine Schnittstelle ohne Kabel, etwa für Dienstadressen) und `veth` (ein Paar, dessen Enden miteinander verbunden sind, Grundlage für Container). Umbenennen geht mit `ip link set X name Y`, aber nur, solange X ausgeschaltet ist.
</Karte>

## Routen

<Karte nr={3} titel="Wohin mit Paketen für fremde Netze">
Für jedes Ziel sucht der Kernel die Route mit dem **längsten passenden Präfix**. Gibt es für dieselbe Länge mehrere, gewinnt die kleinste **Metrik**. Die Standardroute `default` (0.0.0.0/0) passt immer, aber am schlechtesten.

```
sudo ip route add 10.20.30.0/24 via 10.20.20.1
sudo route add -net 10.20.30.0 netmask 255.255.255.0 gw 10.20.20.1      # net-tools
ip route get 10.20.30.7                                                   # welche Route gilt?
```

Das Gateway muss in einem Netz liegen, das direkt erreichbar ist, sonst meldet `ip` „Nexthop has invalid gateway“. In `route -n` steht in der Spalte Flags **U** für eine aktive Route, **G** für den Weg über ein Gateway und **H** für eine Route zu einem einzelnen Rechner.
</Karte>

<Merke>ip addr add … label, ip link add … type vlan id N, ip link set … mtu, ip route add NETZ via GW. ifconfig sieht weitere Adressen nur mit Label. Nichts davon übersteht einen Neustart.</Merke>
