werkstatt rechnet nachts große Messreihen aus, und dabei wird der Speicher knapp. Neu kaufen ist erst nächstes Jahr drin. Bis dahin soll mehr Auslagerungsspeicher helfen: die Swap-Partition auf der neuen SSD und zusätzlich eine Swap-Datei auf der schnellen NVMe, die bevorzugt benutzt wird. **Deine Mission: Richte Swap auf einer Partition und in einer Datei ein, steuere mit Prioritäten, welcher Bereich zuerst dran ist, und mach alles dauerhaft.** Lernziel 203.1 (Swap) und 203.2 (mkswap).

## Partition oder Datei

<Karte nr={1} titel="Zwei Wege zum Auslagerungsspeicher">
Swap ist Platz auf der Platte, in den der Kernel selten benutzte Speicherseiten auslagert. Das hält Programme am Leben, wenn der Arbeitsspeicher knapp wird, ist aber viel langsamer als RAM.

**Swap-Partition:** eine Partition vom Typ „Linux swap“ (GPT 8200, MBR 82). `mkswap /dev/sdb2` schreibt die Swap-Signatur samt UUID, `swapon /dev/sdb2` schaltet sie ein.

**Swap-Datei:** eine ganz normale Datei, die du jederzeit anlegen, vergrößern oder löschen kannst, ohne zu partitionieren.

```
fallocate -l 2G /swapfile          # oder: dd if=/dev/zero of=/swapfile bs=1M count=2048
chmod 600 /swapfile                 # sonst kann jeder ausgelagerten Speicher lesen
mkswap /swapfile
swapon /swapfile
```

Die Rechte sind wichtig: Im Auslagerungsspeicher können Passwörter und Schlüssel landen. mkswap und swapon warnen deshalb bei allem außer 0600. Auf Btrfs braucht eine Swap-Datei Sonderbehandlung, auf ext4 und XFS geht es so.

Was aktiv ist, zeigen `swapon --show`, `swapon -s` und `/proc/swaps`. `free -h` zeigt nur die Summe.
</Karte>

## Prioritäten

<Karte nr={2} titel="Wer zuerst dran ist">
Hat ein Rechner mehrere Swap-Bereiche, entscheidet die **Priorität** (-1 bis 32767): Der Kernel füllt zuerst den Bereich mit der höchsten Zahl. Haben mehrere dieselbe Priorität, verteilt er die Seiten abwechselnd auf alle, ähnlich wie RAID 0. Ohne Angabe vergibt der Kernel negative Werte, -2, -3 und so weiter in der Reihenfolge des Einschaltens.

Setzen kannst du sie beim Einschalten mit `swapon -p 10 /swapfile` oder dauerhaft in der fstab:

```
/swapfile                                  none  swap  sw,pri=10  0  0
UUID=e4d3c2b1-a090-4f8e-9d7c-6b5a4f3e2d1c  none  swap  sw,pri=5   0  0
```

`swapon -a` schaltet alle Swap-Zeilen der fstab ein, `swapoff -a` alle Bereiche aus. swapoff muss vorher alles zurück in den Arbeitsspeicher holen, was dort ausgelagert ist. Auf einem Rechner unter Speichernot kann das dauern oder scheitern.
</Karte>
