Und die Verträge und Zugangsdaten des Labors sollen auf eine eigene, verschlüsselte Partition, die beim Start nach dem Passwort fragt. **Deine Mission: Bau ISO-9660- und UDF-Abbilder, häng sie per Loop ein und richte eine LUKS-Partition samt crypttab ein.** Lernziel 203.3 (CDs und Verschlüsselung).

## Abbilder für CD, DVD und Verteilung

<Karte nr={1} titel="ISO 9660, seine Erweiterungen und UDF">
**ISO 9660** ist das Dateisystem von CDs, auch heute noch von Installations-ISOs. Pur ist es sehr eingeschränkt: Dateinamen nach 8.3 in Großbuchstaben mit Versionsnummer (`LIESMICH.TXT;1`), keine Rechte, keine Links. Darum gibt es Erweiterungen:

| Erweiterung | Bringt | Option bei genisoimage |
|---|---|---|
| **Rock Ridge** | Unix: lange Namen, Rechte, Besitzer, Links | `-R` (oder `-r` mit vernünftigen Standardrechten) |
| **Joliet** | Windows: lange Namen in Unicode | `-J` |
| **El Torito** | Startfähigkeit: ein Boot-Abbild im Katalog | `-b isolinux/isolinux.bin -c boot.cat …` |
| **HFS** | Apple: altes Mac-Dateisystem für Hybrid-CDs | `-hfs` |

Gebaut wird mit **genisoimage**, unter Debian auch als `mkisofs` aufrufbar (aus Paket genisoimage; xorriso aus Mission 3.6 kann es ebenso):

```
genisoimage -o handbuch.iso -R -J -V HANDBUCH ~/handbuch
sudo mount -o loop handbuch.iso /mnt/iso
isoinfo -d -i handbuch.iso
```

Eine ISO-Datei hängst du über ein **Loop-Gerät** ein, das eine Datei wie eine Platte aussehen lässt. ISO 9660 ist immer nur lesbar.

**UDF** (Universal Disk Format) ist das Dateisystem von DVDs und Blu-rays. Es kennt große Dateien und lässt sich auch beschreiben. Angelegt wird es mit `mkudffs` aus dem Paket udftools, eingehängt mit `mount -t udf`.
</Karte>

## Verschlüsselte Partitionen

<Karte nr={2} titel="dm-crypt und LUKS">
**dm-crypt** ist die Verschlüsselung im Kernel: Ein Gerät unter /dev/mapper/ zeigt entschlüsselt, was auf der Partition verschlüsselt liegt. **LUKS** (Linux Unified Key Setup) ist das Format davor: Ein Kopf auf der Partition enthält den eigentlichen Schlüssel, verschlüsselt mit einer oder mehreren Passphrasen in eigenen **Schlüsselfächern**. So kannst du Passphrasen hinzufügen oder ändern, ohne alles neu zu verschlüsseln.

```
cryptsetup luksFormat /dev/sdb1          # löscht alles, fragt nach YES und Passphrase
cryptsetup open /dev/sdb1 tresor         # → /dev/mapper/tresor
mkfs.ext4 /dev/mapper/tresor
mount /dev/mapper/tresor /srv/tresor
umount /srv/tresor
cryptsetup close tresor
```

`cryptsetup luksDump /dev/sdb1` zeigt Kopf und belegte Fächer, `luksAddKey` fügt eine Passphrase hinzu (etwa für den Notfall), `status tresor` zeigt ein geöffnetes Gerät.

Beim Start öffnet systemd Geräte aus **/etc/crypttab** und fragt nach der Passphrase:

```
# Name    Gerät                                       Schlüsseldatei  Optionen
tresor    UUID=8e9f0a1b-2c3d-4e5f-9a6b-7c8d9e0f1a2b   none            luks
```

Die UUID ist die des LUKS-Kopfs (`blkid /dev/sdb1` zeigt TYPE="crypto_LUKS"). In die fstab kommt dann `/dev/mapper/tresor`.
</Karte>
