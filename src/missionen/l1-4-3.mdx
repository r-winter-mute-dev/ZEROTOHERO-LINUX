Die Dateisysteme auf der neuen SSD sind fertig, aber noch unsichtbar. Unter Linux gibt es keine Laufwerksbuchstaben: Jedes Dateisystem wird an einer Stelle in den einen großen Verzeichnisbaum **eingehängt**. **Deine Mission: Häng die Partitionen ein, von Hand, dauerhaft über fstab und als systemd-Unit.** Lernziel 104.3.

## Von Hand

<Karte nr={1} titel="mount und umount">
`sudo mount /dev/sdb1 /mnt/daten` hängt das Dateisystem von sdb1 im Verzeichnis `/mnt/daten` ein. Dieses Verzeichnis heißt **Einhängepunkt** und muss vorher existieren. Den Typ erkennt mount meist selbst, sonst gibst du ihn mit `-t ext4` an. Optionen folgen nach `-o`, etwa `-o ro` für nur lesbar.

Was vorher im Einhängepunkt lag, ist nicht weg, sondern **verdeckt**. Nach dem Aushängen taucht es wieder auf.

`sudo umount /mnt/daten` (oder `umount /dev/sdb1`) hängt wieder aus. Das klappt nur, wenn niemand das Dateisystem benutzt. Steht eine Shell mit `cd` darin oder hat ein Programm eine Datei offen, meldet umount **„das Ziel wird gerade benutzt“**. Wer es benutzt, verraten `lsof /mnt/daten` und `fuser -m /mnt/daten`.

Was gerade eingehängt ist, zeigen `mount` ohne Argumente, `findmnt`, `df -h` und `lsblk`.

Konventionen: `/mnt` für vorübergehend von Hand eingehängte Dateisysteme, `/media` für Wechselmedien, die der Desktop automatisch einhängt (`/media/lena/STICK`).
</Karte>

<Merke>mount GERÄT VERZEICHNIS. Der Einhängepunkt muss existieren. umount scheitert, solange jemand darin arbeitet.</Merke>

## Dauerhaft: /etc/fstab

<Karte nr={2} titel="Die Datei /etc/fstab">
Was beim Start eingehängt werden soll, steht in **/etc/fstab**, eine Zeile pro Dateisystem mit sechs Spalten:

```
# Gerät                                    Einhängepunkt  Typ   Optionen  dump  pass
UUID=b7e1c2d3-4f5a-4b6c-9d7e-8f9a0b1c2d3e  /mnt/daten     ext4  defaults  0     2
```

1. **Gerät**: besser `UUID=…` oder `LABEL=…` als `/dev/sdb1`, denn Gerätenamen können sich ändern, wenn eine Platte dazukommt. UUID und Label zeigen `blkid` und `lsblk -f`.
2. **Einhängepunkt**, bei Swap `none`.
3. **Typ**: ext4, xfs, vfat, swap …
4. **Optionen**, durch Komma getrennt: `defaults` (rw, suid, dev, exec, auto, nouser, async), `noauto` (nicht beim Start), `user` (normale Benutzer dürfen einhängen), `ro`, `noexec`, `nosuid`, `nodev`, `noatime`.
5. **dump**: 1 heißt, das alte Programm dump soll sichern. Heute fast immer 0.
6. **pass**: Reihenfolge für fsck beim Start. 1 für `/`, 2 für alle anderen, 0 für nie (Swap, vfat oft).

`sudo mount -a` hängt alles aus der fstab ein, was noch fehlt, außer `noauto`. Damit testest du eine neue Zeile, bevor du neu startest. Ein Tippfehler in der fstab kann sonst den Start in den Notfallmodus schicken.

`mount /mnt/daten` mit nur einer Angabe holt sich den Rest aus der fstab. `mount -o remount,ro /mnt/daten` ändert die Optionen, ohne auszuhängen.
</Karte>

<Merke>fstab: Gerät, Punkt, Typ, Optionen, dump, pass. UUID statt /dev/sdX. Neue Zeile mit mount -a testen.</Merke>

## systemd-Mount-Units

<Karte nr={3} titel="Einhängen als systemd-Unit">
systemd liest die fstab beim Start und macht aus jeder Zeile intern eine **Mount-Unit**. Du kannst solche Units auch selbst schreiben, unter `/etc/systemd/system/`:

```
[Unit]
Description=Archiv auf der zweiten SSD

[Mount]
What=/dev/disk/by-uuid/5a6b7c8d-9e0f-4a1b-8c2d-3e4f5a6b7c8d
Where=/mnt/archiv
Type=xfs
Options=defaults

[Install]
WantedBy=multi-user.target
```

Die wichtigste Regel: Der **Dateiname muss zum Einhängepunkt passen**. Aus `/mnt/archiv` wird `mnt-archiv.mount`, die Schrägstriche werden zu Bindestrichen. `systemd-escape -p --suffix=mount /mnt/archiv` rechnet das aus. Passt der Name nicht, verweigert systemd die Unit.

Danach: `systemctl daemon-reload` (systemd liest Unit-Dateien neu), `systemctl start mnt-archiv.mount` (jetzt einhängen) und `systemctl enable mnt-archiv.mount` (beim Start). Eine `.automount`-Unit mit gleichem Namen hängt erst beim ersten Zugriff ein.

`daemon-reload` brauchst du auch nach Änderungen an der fstab, damit systemd die neue Fassung kennt. Darum hat dich mount oben daran erinnert.
</Karte>

<Merke>Unit-Name = Pfad mit Bindestrichen: /mnt/archiv → mnt-archiv.mount. daemon-reload, start, enable.</Merke>

<Hinweis titel="Prüfungstipp">
Die fstab kommt in jeder Prüfung 101 vor: Reihenfolge der Spalten, Bedeutung von pass, Optionen wie noauto, user, ro. Dazu UUID und LABEL mit blkid. Bei systemd genügt meist, dass Mount-Units nach dem Einhängepunkt benannt sind und auf `.mount` enden.
</Hinweis>
